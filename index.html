How to Upload Your Certificate
# 1. Convert .p12 to PEM (if needed)
openssl pkcs12 -in utility_cert.p12 -clcerts -nokeys -out cert.pem

# 2. Upload to Cloudflare
npx wrangler mtls-certificate upload \

# 4. Add to wrangler.toml (see Program Builder)
[[mtls_certificates]]
binding = "VTN_CERT"

⚙️ Runtime Monitor — Firmware Command Settings
Saved
Controls the current-change bubble-up flag on measurement-equipped devices. Setting bit 8 (0x80) in the device's bubble flag register activates a forced bubble-up every time the current measurement transitions between zero and non-zero — giving the platform equipment start and stop timestamps. Clearing it returns the device to normal scheduled reporting. Commands are built as Assignment Command 0x1A / Designator 0x03 and delivered via note.add to data.qi.
▶ ACTIVATE — Set bit 8 (0x80)
—

⏹ DEACTIVATE — Clear bit 8 (0x00)
—
